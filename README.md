# Fintech Landing Page – Pixel Perfect UI

Pixel-perfect implementation of a fintech landing page based on a free **Figma Community** design.

This project focuses on accurately translating a real UI design into code, paying close attention to spacing, typography, colors, and responsive behavior.

## 🔗 Design reference
- Figma Community design:  
  https://www.figma.com/community/file/1134735817018868150/fintech-landingpage-concept

> Design credits belong to the original designer.  
> This implementation is for educational and portfolio purposes.

## 🚀 Tech stack
- React
- TypeScript
- Tailwind CSS
- Vite

## ✨ Highlights
- Pixel-perfect UI based on Figma design
- Fully responsive (mobile, tablet, desktop)
- Clean and reusable React components
- Performance-focused implementation
- Modern frontend tooling

## 📱 Responsive design
The layout adapts correctly across different screen sizes, maintaining visual consistency and usability.
